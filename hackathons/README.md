## Project Concept: Privacy-First Context Firewall & Compiler (Jira Custom UI)
1. **Pulls Messy Data:** Reads real Jira tickets, comments, and Confluence docs (+ 1-click sample company tickets for judges).
2. **Local Privacy Filter (Pure JS — Zero AI):** Regex + labels (`Name:`, `DOB:`, `Patent:`) + Jira metadata + `compromise` + Entity Vault swaps secrets for `[NAME_1]`, `[DOB_1]`, etc.
3. **Safety Score (0–100%) & Gov-File `Before | After` Screen:** Score >= 90% auto-sends; < 90% pauses on `██████` blackout preview for 1-click manual redaction + optional private NVIDIA privacy check.
4. **NVIDIA / Private LLM Organizes -> Pure JS Re-Fills:** Extracts clean fields (`Patent Name`, `DOB`, `Missing Info`) into a React Custom UI table inside Jira, then restores real values locally.
5. **Bonus Hooks:** `rovo:agent` + `rovo:action`, Forge MCP server, Teamwork Graph, Marketplace listing, plus interactive Cursor Buddy.
