# Kiroween 2026 Feature Spec

## Goal
Build a polished, hauntingly memorable interactive feature/theme inside LaunchVault using Kiro IDE, Hooks, and Steering before Dec 4, 2026.

## Requirements
1. **Thematic UI Enhancement (Costume Contest):** Provide a cohesive, high-contrast "After-Hours Vault / Startup Autopsy" visual mode that enhances readability and storytelling without breaking WCAG AA contrast or existing workflows.
2. **Actionable Output:** Every story or failure autopsy must still end in a concrete, saveable weekly checklist step for students.
3. **Zero Regressions:** Existing `build.py` and `build_app.py` outputs, links, and `prefers-reduced-motion` support must remain intact.
