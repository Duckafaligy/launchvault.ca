How we check numbers. Every number has a label and a date.

Most revenue numbers online are screenshots. They can be cropped, rounded or edited, and you can't tell. Here's how every number on LaunchVault is sourced, labelled and corrected.

The four labelsSourcesOur rulesCorrections logFor parents

The four labels.

Each number gets exactly one, plus the date we read it.

Verified

Read from a live source

Like Stripe revenue read through TrustMRR, on the date shown. TrustMRR connects with a read-only key, so the number can't be typed in by hand.

$430,896 a month · Postiz · Nov 17 2026

Claimed

Said, not checked

Said by the founder, in an interview or in a case study. We link to where they said it, but we couldn't check it against a live source.

$250 to start · Windmill Growth, he says

Sources differ

Two sources disagree

We show both numbers and say which one the chart uses, so you can judge for yourself.

$21K or $45K · Postiz, Mar 2026

Live

Refreshed from the source

Read from the source itself, like GitHub stars, with the time we read it. It can change by tomorrow.

41,810 stars · Postiz · Nov 17 2026

One label and a date on every number

We show the date a number was read, not today's date. If a source stops updating, the old date stays, like Gojiberry's Aug 14 2026 on TrustMRR.

Both numbers when sources disagree

We never quietly pick the nicer one. Both go on the page with a Sources differ label, and we say which one the chart uses.

Fixes are logged, not hidden

If we get a number wrong, we fix it on the breakdown and add a line to the corrections log below: the date, the old number and the new one.
